# Оформление из макета Figma

Макет: **«Монтик»**, https://www.figma.com/design/fRE5bxFESOizTbv7now5aL/Монтик

Интерфейс игры собран по этому макету: цвета, шрифт, скругления, размеры кнопок и расположение
элементов взяты из него один к одному. Кадр макета 412×917 — это обычный телефон, поэтому числа
из Figma используются в коде как dp без пересчёта.

## Чего в игре пока нет и почему

Растровые иллюстрации из макета (фоны городов, комната, касса, полки магазина, сам персонаж)
не встроены: их нельзя выгрузить из Figma автоматически в этой среде. Вместо каждой из них
игра рисует похожий запасной фон кодом. **Как только вы положите PNG с нужным именем в папку
ресурсов, игра начнёт показывать его сама — менять код не нужно.**

### Куда класть файлы

`app/src/main/res/drawable-nodpi/`

Если папки нет, создайте её. Имена — только строчные латинские буквы, цифры и `_`, расширение `.png`
(или `.webp`, `.jpg`).

### Как выгрузить из Figma

1. Откройте макет и выделите нужный фрейм или слой (например, только фон, без текста и кнопок).
2. Справа в блоке **Export** выберите **PNG**, масштаб **2x**, нажмите **Export**.
3. Переименуйте файл по таблице выше и положите в `drawable-nodpi`.
4. Пересоберите приложение (**Run ▶**).

Совет: чтобы в файл не попали лишние элементы, временно выключите слои с текстом и кнопками
или скопируйте фон в отдельную рамку.

## Шрифт

В макете использован **Ubuntu Mono** (Bold и Regular). В проект он не вложен: шрифт нужно
добавлять самому, проверив условия лицензии. Пока используется системный моноширинный шрифт —
он даёт тот же характер.

Чтобы подключить настоящий Ubuntu Mono:

1. Скачайте `UbuntuMono-Regular.ttf` и `UbuntuMono-Bold.ttf` (Google Fonts, лицензия Ubuntu Font Licence).
2. Положите их в `app/src/main/res/font/` под именами `ubuntu_mono_regular.ttf` и `ubuntu_mono_bold.ttf`.
3. В `ui/Theme.kt` замените строку

   ```kotlin
   private val Mono = FontFamily.Monospace
   ```

   на

   ```kotlin
   private val Mono = FontFamily(
       Font(R.font.ubuntu_mono_regular, FontWeight.Normal),
       Font(R.font.ubuntu_mono_bold, FontWeight.Bold)
   )
   ```

   и добавьте импорты `androidx.compose.ui.text.font.Font` и `ru.montik.app.R`.
4. Допишите шрифт в `docs/LICENSES.md`.

## Цвета и формы

Всё оформление задано в одном файле `app/src/main/java/ru/montik/app/ui/Theme.kt`:

- `Ink` `#0A3652` — весь текст;
- `Lime` `#C1FA86` — главные кнопки;
- `Cream` `#FEFFFA` — фон экранов;
- белые карточки со скруглением 20, кнопки-пилюли высотой 73;
- цвета круглых кнопок главного экрана (Голод, Сон, Усталость, Телефон, Кошелёк).

## Значок приложения

Значок собран из `res/drawable/ic_launcher_foreground.xml` и цвета `ic_launcher_background`
(сейчас лаймовый `#C1FA86`, как в макете). Версия 512×512 для магазина: `docs/store/icon_512.png`.
Чтобы заменить: правый клик по `res` → **New → Image Asset**.
