# Оформление из макета Figma

Макет: **«Монтик»**, https://www.figma.com/design/fRE5bxFESOizTbv7now5aL/Монтик

Интерфейс игры собран по этому макету: цвета, шрифт, скругления, размеры кнопок и расположение
элементов взяты из него один к одному. Кадр макета 412×917 — это обычный телефон, поэтому числа
из Figma используются в коде как dp без пересчёта.

**Как подготовлены картинки из макета.** В рекламе стёрты цифры «1500» в зелёной звезде «ВЫГОДА» —
цену рисует код (`ui/AdUi.kt`), она зависит от уровня Монтика: базовая × 1 / 3 / 10. Прозрачные
участки внутри баннеров залиты белым, чтобы на затемнённом экране реклама выглядела как в макете.
По ТЗ (никакой рекламы реальных брендов) закрашены логотипы: яблоко на телефоне (`fg_ad_phone`),
буква «b» на наушниках (`fg_ad_thing`) и надписи на корешках книг в богатой комнате (`fg_room3_*`).
Координаты кнопки «КУПИТЬ», крестика и места цены сняты с картинок и записаны в `LAYOUTS` в `ui/AdUi.kt`;
если заменить баннер своим, поправьте там доли (0..1 от стороны картинки).

Время суток: 05:00–16:59 — `_day`, 17:00–19:59 — `_dusk`, 20:00–22:59 — `_evening`, 23:00–04:59 — `_night`
(у кухни вечер и ночь — `_night`). `_sleep` — экран сна на уровнях 2 и 3.

Заготовки Монтика (`HeroPreset`: белый человечек, синий, зелёный, розовый, фиолетовый, рыжий) сделаны из тех же рисунков Figma перекрашиванием шерсти; корона, рюкзак, глаза и ушки остались как в макете. Новая игра начинается с белого человечка, которого ребёнок раскрашивает на экране «Нарисуй Монтика»; можно заменить любой `fg_hero_*` своим рисунком — то же имя, без правок кода. Раскрашенный вручную герой рисуется кодом (`MontikBunny`).

Комната зависит от **виртуального времени Монтика** (1 настоящая минута = 150 виртуальных): с 17:00 до 4:59 — закат (`fg_room_dusk`), днём — светлая комната (`fg_room_morning`), а в первый день игры — комната с чемоданом и коробками (`fg_room_day`, кадр «переезд»).
Ночная комната `fg_room_night` (Монтик спит в кровати) показывается на экране сна, а утренняя `fg_room_morning` — на экране «Монтик проснулся», где герой стоит возле кровати.
Экран будильника «Просыпайся!» рисуется кодом по кадру макета (лаймовый фон, белая карточка, будильник, кнопки «Выключить» и «Отложить на 15 минут»); отдельных картинок для него не нужно.
Шрифт макета — Ubuntu Mono; пока используется системный моноширинный (кегль уменьшен в
`MONO_SCALE`, чтобы строки переносились так же). Положите Ubuntu Mono в `res/font` и поставьте
`MONO_SCALE = 1f`, чтобы совпало ещё точнее.

### Как выгрузить из Figma

1. Откройте макет и выделите нужный фрейм или слой (например, только фон, без текста и кнопок).
2. Справа в блоке **Export** выберите **PNG**, масштаб **2x**, нажмите **Export**.
3. Переименуйте файл по таблице выше и положите в `drawable-nodpi`.
4. Пересоберите приложение (**Run ▶**).

Совет: чтобы в файл не попали лишние элементы, временно выключите слои с текстом и кнопками
или скопируйте фон в отдельную рамку.

## Шрифт

В макете использован **Ubuntu Mono** (Bold и Regular). В проект он не вложен: шрифт нужно
добавлять самому, проверив условия лицензии. Пока используется системный моноширинный шрифт —
он даёт тот же характер.

Чтобы подключить настоящий Ubuntu Mono:

1. Скачайте `UbuntuMono-Regular.ttf` и `UbuntuMono-Bold.ttf` (Google Fonts, лицензия Ubuntu Font Licence).
2. Положите их в `app/src/main/res/font/` под именами `ubuntu_mono_regular.ttf` и `ubuntu_mono_bold.ttf`.
3. В `ui/Theme.kt` замените строку

   ```kotlin
   private val Mono = FontFamily.Monospace
   ```

   на

   ```kotlin
   private val Mono = FontFamily(
       Font(R.font.ubuntu_mono_regular, FontWeight.Normal),
       Font(R.font.ubuntu_mono_bold, FontWeight.Bold)
   )
   ```

   и добавьте импорты `androidx.compose.ui.text.font.Font` и `ru.montik.app.R`.
4. Допишите шрифт в `docs/LICENSES.md`.
