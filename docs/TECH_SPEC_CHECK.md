# Сверка с техническим заданием

Проект сверялся с двумя источниками: описанием идеи и MVP (документы «Что делает Монтик» и «Задания») и
техническим заданием организаторов (разделы 3.1–3.5, присланы скриншотами). Ниже требования сгруппированы по темам.
Если формулировка пункта ТЗ в вашей копии отличается, сверьте строку таблицы с оригиналом.

Обозначения: ✅ сделано, 🟡 сделано частично или требует действия автора, ⏳ запланировано на следующие версии.

## Платформа и сборка

| Требование | Статус | Как выполнено |
| --- | --- | --- |
| Приложение для Android 8.0 и новее | ✅ | `minSdk = 26` в `app/build.gradle.kts` |
| Работа без интернета | ✅ | В манифесте нет разрешения `INTERNET`; всё хранится в памяти приложения |
| Минимум разрешений, только обоснованные | ✅ | Разрешений нет. Снимок делает системная «Камера» через `FileProvider`, поэтому `CAMERA` не нужен |
| Установка из APK-файла | 🟡 | Проект готов к сборке. Подписанный APK автор собирает у себя по README (нужен ваш ключ подписи: он секретный и не хранится в проекте) |
| Готовность к публикации в RuStore | 🟡 | Иконка 512×512, черновик карточки и политики: `docs/STORE_LISTING.md`. Скриншоты снимаются с готового приложения |
| Исходный код, README, инструкция по сборке | ✅ | `README.md`, Gradle-проект, wrapper |
| Автоматические тесты | ✅ | 31 тест (`gradlew test`), описание в `docs/TEST_CASES.md` |
| Лицензии и происхождение материалов | ✅ | `docs/LICENSES.md`: сторонних картинок, шрифтов и звуков нет |

| Требование | Статус | Где в приложении |
| --- | --- | --- |

| Обработка рисунка на устройстве, без облака | ✅ | Классическая обработка изображения в `drawing/DrawingCutout.kt` |
| Потребности: еда, вода, жильё | ✅ | Магазин (еда и вода), сон (домик или скамейка) |

| Подсказка при съёмке рисунка | ✅ | Примеры «так получится / так не выйдет», нарисованные кодом, и четыре коротких совета |

## Безопасность детей и данные

| Требование | Статус | Комментарий |
| --- | --- | --- |
| Никакой рекламы и встроенных покупок | ✅ | Нет |
| Нет внешних ссылок, чатов, учётных записей | ✅ | Нет |
| Данные ребёнка не покидают устройство | ✅ | Нет сети; прогресс в файле в памяти приложения; резервное копирование в облако Android отключено (`allowBackup=false`) |
| Фото рисунка не хранится | ✅ | После подтверждения снимок удаляется, остаётся только вырезанный герой |
| PIN родителя защищён | ✅ | Хранится как SHA-256 с солью, не в открытом виде |
| Использование ИИ | ✅ | Нейросети и облачных сервисов нет. Вырезание рисунка — обычный алгоритм обработки изображения. Ребёнок всегда видит результат и подтверждает его |

## Что нужно сделать автору перед сдачей

1. Открыть проект в Android Studio, дождаться синхронизации и запустить на эмуляторе или телефоне.
2. Пройти ручной сценарий из `docs/TEST_CASES.md`.
3. Создать ключ подписи и собрать `assembleRelease` по README.
4. По желанию положить иллюстрации из Figma по инструкции `docs/DESIGN_ASSETS.md`.
5. Снять скриншоты для магазина (план в `docs/STORE_LISTING.md`).
