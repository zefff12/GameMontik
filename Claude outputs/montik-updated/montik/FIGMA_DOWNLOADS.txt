🎨 Frame 33 - Раскраска персонажа (8 вариантов Монтика):
═══════════════════════════════════════════════════════════════════

Если у вас есть доступ в интернет и Figma откроется, просто нажмите 
на фреймы ниже и используйте "Export" или скопируйте их вручную.

Самый простой способ:
1. Откройте Figma в браузере: 
   https://www.figma.com/design/fRE5bxFESOizTbv7now5aL/Монтик

2. Найдите фреймы:
   - Frame 33 (ID: 438:136) - 8 цветных вариантов Монтика
   - Frame 34 (ID: 443:155) - еще один вариант

3. Right-click на фрейм → Export → PNG (или WebP)

4. Положите файлы в: figma_assets/skins/

 ЕСЛИ FIGMA НЕ ОТКРЫВАЕТСЯ:
═══════════════════════════════════════════════════════════════════

Используйте этот curl скрипт (для Linux/Mac):

#!/bin/bash
mkdir -p figma_assets/{skins,barter,credits,ui,raccoon}

# Скачивайте Frame 33 и Frame 34
# (требует Figma токен или публичный доступ)

═══════════════════════════════════════════════════════════════════
 АЛЬТЕРНАТИВА - РУЧНОЙ ЭКСПОРТ:
═══════════════════════════════════════════════════════════════════

Откройте в Figma файл и:

1. Найдите Frame 33 в левой панели
2. Нажмите правой кнопкой мыши
3. Выберите "Export"  
4. Установите:
   - Format: PNG (или WebP для сжатия)
   - Scale: 1x
5. Нажмите "Export"
6. Положите файл в figma_assets/skins/frame_33.png

Повторите для:
- Frame 34
- Android Compact скинов
- Других нужных компонентов
