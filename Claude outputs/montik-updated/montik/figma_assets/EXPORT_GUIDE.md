## 📋 Как экспортировать (подробно)

1. **Откройте Figma**
   - Перейдите на: https://www.figma.com/design/fRE5bxFESOizTbv7now5aL/Монтик

2. **Найдите фрейм**
   - В левой панели найдите "Frame 33" или нужный фрейм
   - Кликните на него (чтобы выделился синей рамкой)

3. **Экспортируйте**
   - **Способ 1:** Right-click на фрейм → "Export" → PNG
   - **Способ 2:** Нажмите на фрейм, в правой панели найдите "Export" → добавьте нужный формат

4. **Сохраните файл**
   - Figma автоматически скачает PNG файл
   - Переместите его в соответствующую папку:
     - Скины → `figma_assets/skins/`
     - Енот → `figma_assets/raccoon/`
     - UI элементы → `figma_assets/ui/`

## 🔧 Оптимизация размера

Figma экспортирует в PNG, но можно сжать без потери качества:

**На Mac/Linux:**
```bash
# Установите ImageMagick
brew install imagemagick

# Конвертируйте PNG в WebP (размер уменьшится в 2-3 раза)
cwebp frame_33.png -o frame_33.webp

# Или просто сожмите PNG
mogrify -quality 90 *.png
```

**На Windows:**
- Используйте онлайн конвертер: https://cloudconvert.com/

## ✅ Когда всё готово

1. Убедитесь что все файлы в папке `figma_assets/`
2. Создайте архив: `zip -r figma_assets.zip figma_assets/`
3. Закиньте `figma_assets/` папку в:
   ```
   GameMontik/app/src/main/res/drawable-nodpi/
   ```
4. Напишите мне "готово!" и я внедрю ассеты в код
