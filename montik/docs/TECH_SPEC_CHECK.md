# Матрица соответствия ТЗ

Сверка с техническим заданием «Мобильное приложение „Питомец Финни“ — игровой сервис для формирования базовых
финансовых навыков у детей 7–11 лет» (Департамент финансов города Москвы, 2026) и с ответами на вопросы сессии.
Питомец в нашей реализации — Монтик (по ответам организаторов имя и вид персонажа команда выбирает сама).

Обозначения: ✅ сделано, 🟡 сделано частично или требует действия автора, ⏳ план.

## Правила расчёта (кратко)

| Что | Правило |
| --- | --- |
| Игровое время | 1 настоящая минута = 150 минут у Монтика (сутки ≈ 10 минут) |
| Игровой период | 5 игровых дней; в начале — план, в конце — итоги и звёзды |
| Квартира | Платёж 15-го и 30-го числа игрового месяца (каждые 15 дней). За 5 дней — отсчёт на главном экране; можно заплатить заранее. В срок: кошелёк → подушка → остаток становится долгом (без выселения). Ночь дома бесплатная |
| Аренда по уровням | 150 / 400 / 1500 монет; переезд 0 / 300 / 2000; звёзд нужно 0 / 6 / 15 |
| Звезда «Обязательное» | Нет долга за квартиру и ни одной голодной ночи за период |
| Звезда «План» | План подтверждён, и факт по обязательному и желаемому не больше плана (допуск 10%, не меньше 5 монет) |
| Звезда «Копилка» | Отложено больше 0 и не меньше, чем по плану |
| Срок до цели | (цена − накоплено) ÷ средняя сумма пополнения в день с первого пополнения, округление вверх |
| Награда за задание | Первый раз: «отлично» — полная, «неплохо» — 2/3, «можно лучше» — 1/3 (не меньше 5). Повтор — без монет |
| Реклама | Каждый третий игровой день; цена = базовая × 1 / 3 / 10 по уровню; крестик — деньги остаются, «Купить» — желаемая трата |
| Настроение | Радости и покупки поднимают, за ночь −6; причина изменения показывается ребёнку |
| Опыт и уровень Монтика | Смена +15 (в магазине ещё +5 за звезду), задание в первый раз +30/+20/+10, копилка +5 раз в день, звезда привычек +15, цель достигнута +50, отказ от рекламы +10, переезд +40. На уровень: 60, 90, 120… опыта |
| Звёзды смены в магазине | 90+ — ★★★, 70+ — ★★, иначе ★; лучший результат по каждой мини-игре запоминается |
| События дня | С 3-го дня, не чаще раза в 2 дня, шанс 45%: потерянный ключ (из подушки) или доброе событие — соседка, находка, подарок, «скидка» |

## 3. Программно-аппаратные требования и безопасность

| Требование | Статус | Комментарий |
| --- | --- | --- |
| Android 8.0+, портрет от 360 dp | ✅ | `minSdk = 26`; кадр 412×917 масштабируется под экран |
| Без интернета, без лишних разрешений | ✅ | Разрешений нет, снимок рисунка делает системная «Камера» |
| Разделение экономики, контента, хранения и интерфейса | ✅ | `game/` (правила и контент, чистый Kotlin), `data/` (хранение), `ui/` (экраны) |
| Автотесты ключевой логики | ✅ | `GameEngineTest` и `LifeTest`: бюджет, списания, накопления, прогресс |
| Нет рекламы, платных подписок, внутриигровых покупок | ✅ | «Рекламное предложение» — вымышленная учебная ситуация за игровые монеты с подписью «Реклама · учебная ситуация»; логотипы реальных брендов с картинок убраны |
| Тексты не запугивают и не стыдят | ✅ | Нет болезней и выселения; уровни названы «скромный достаток / средний достаток / богатый» |
| Вовлечение без давления | ✅ | Нет серий со штрафом за пропуск, push-уведомлений и случайных наград за деньги; интерес — от отклика, уровня, коллекции и похвалы взрослого |
| Сброс и удаление данных взрослым | ✅ | Раздел взрослого и настройки Android |

## Что нужно сделать автору перед сдачей

1. Собрать проект в Android Studio и пройти сценарий из `docs/TEST_CASES.md` (раздел «Сквозной сценарий ТЗ»).
2. Проверить на физическом телефоне (ТЗ 3.1) и записать короткий отчёт: модель, Android, ОЗУ, что проверено.
3. Собрать подписанный APK по README.
4. Подготовить презентацию (8–12 слайдов) и видео демонстрации до 3 минут.
