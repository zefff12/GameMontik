# Тестирование

## 1. Автоматические тесты

Запуск: `gradlew.bat test` (Windows) или `./gradlew test`. Проверяют ядро игры и вырезание рисунка, Android для них не нужен.

**Правила, экономика, сон и время (`GameEngineTest`)**

| Что проверяется |
| --- |
| Стартовый кошелёк 50 монет; лучший выбор во вступительной ситуации (обед) оставляет 40 и записывается как обязательная трата |
| Расчётный листок: смена помощника даёт 35 «начислено», налог 13% = 5, «на руки» 30; налог попадает в статистику, открывается урок «Налог 13%» |
| Верный ответ на задание даёт премию +20% (35 → 42) и очко навыка «Создатель» |
| Уставший Монтик зарабатывает меньше |
| Монтик снимает квартиру: ночь дома бесплатная, силы восстанавливаются полностью даже без денег |
| Одежда изнашивается, дешёвая раньше дорогой; «Продавец» открывается после 3 смен и 2 надетых вещей |
| Подушка безопасности покрывает непредвиденную трату; очки «Банкира» за вехи даются один раз |
| Дневник и бонус «Планировщика», когда отложено не меньше 20% заработка |
| Путешествия открываются по цепочке и заканчиваются после трёх остановок |
| Виртуальные часы: 1 настоящая минута = 150 виртуальных (в 3 раза быстрее прежнего); идут и пока игра закрыта |
| План сна: днём Монтик ложится в 21:00, вечером и ночью — сразу; будильник — на ближайшие 07:00 |
| Таймер сна: сколько проспал, сколько осталось, когда звонит будильник; спящий Монтик не работает и не ложится второй раз |
| «Отложить»: сон продолжается, будильник звонит снова через 15 виртуальных минут |
| Выспался (8 ч и больше в домике): 100 сил и смена за 30; не выспался (меньше 6 ч): смена за 45; ранний подъём даёт часть сил; скамейка — не выше 55 |
| Сон и качество сна сохраняются; старое сохранение без часов начинает каждый день в 07:00; смена сдвигает время на 3 часа |
| В каждой ситуации есть вариант, который по карману даже без монет; в каждом задании ровно один верный ответ |
| Сохранение и загрузка состояния без потерь |
| Заготовки Монтика: игра начинается с белого человечка, есть синий, зелёный и другие; раскраска ложится поверх заготовки и сохраняется; неизвестная заготовка не ломает загрузку, а старое сохранение остаётся синим |
| «Бот-игрок» доходит до поездки в Москву за разумное число дней (не больше 25) |
| Без сил, еды или воды (меньше 10) смена недоступна, монеты не начисляются |
| Мелкое поручение выручает, когда нет ни монет, ни подушки, ни еды, и исчезает, как только Монтик в порядке |
| В текстах игры нет болезней, лечения и смерти |
| Вклад приносит проценты только за полный день, а снятый раньше — нет |
| Кредит возвращается с переплатой, второй кредит не дают, с долгом нельзя открыть вклад |
| Сочи открывается последним, стоит 500 монет и полностью восстанавливает силы |
| Медаль выдаётся один раз и не пропадает, даже если потратить накопленное |

**Вырезание рисунка (`DrawingCutoutTest`, 6 тестов)**

| Что проверяется |
| --- |
| Фон-бумага становится прозрачным |
| Рисунок с контуром вырезается, белое «внутри» героя остаётся |
| Цветная закрашенная фигура находится |
| Пылинки и мелкий мусор игнорируются |
| Небольшой разрыв в контуре не «съедает» внутренность |
| Пустой лист даёт понятную ошибку, а не пустого героя |

**Требования ТЗ: квартира, план и факт, уровни, копилка, задания, реклама (`LifeTest`, 24 теста)**

| Что проверяется |
| --- |
| Квартира оплачивается 15-го и 30-го числа; за 5 дней появляется отсчёт; досрочная оплата — только в дни отсчёта и не списывается второй раз |
| Не хватило на квартиру: сначала берётся подушка, остаток — долг; никто не выселяет, долг можно погасить |
| План не может быть больше денег в кошельке, виден остаток; черновик меняется, подтверждённый — нет |
| Хороший период даёт 3 звезды; перерасход на желаемое и «ничего не отложено» отнимают звёзды с понятным объяснением; голод или долг за квартиру — без звезды «обязательное» |
| Траты делятся на обязательные и желаемые и попадают в историю периода; покупка без денег не проходит и объясняет, чего не хватает |
| Переезд вверх требует звёзд и денег, вниз — бесплатный; аренда и цена рекламы растут с уровнем |
| Копилка: остаток, средний темп, срок до цели; перед снятием видно, как отодвинется цель; достигнутая цель тратит копилку (вещь или билет) |
| Задания: не меньше 6 по 3 темам, у каждого есть верное решение и объяснение; неверные ответы тоже объясняются; монеты — только за первое прохождение; открываются по дню, в демо — все |
| Реклама появляется каждый третий день; крестик сохраняет деньги; покупка списывает монеты в «желаемое»; в долг по рекламе купить нельзя |
| Настроение растёт от радостей, падает за ночь и объясняется; кухня: еда стоит денег и кормит, «не есть» бесплатно, но объяснено |
| Демо-режим: 5 периодов подряд без ожидания по тем же правилам |
| Все новые поля сохраняются и загружаются без потерь; старое сохранение получает ближайший день оплаты |
| Обычный игрок (помощник мастера) за месяц оплачивает скромную квартиру без долгов |

## 2. Ручной сценарий для показа (7–10 минут)

Подготовьте лист белой бумаги с нарисованным героем (тёмный контур, лист целиком в кадре).
Чтобы начать заново, используйте «Родитель → Удалить весь прогресс» или очистите данные приложения.

| № | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Запустить приложение | Заставка «Монтик», кнопка «Начать» |
| 2 | Нажать «Начать», пролистать стрелкой 5 страниц истории, нажать «Вперёд!» | Открывается экран «Нарисуй Монтика!» |
| 3 | Нажать «Сфотографировать рисунок» (или «Выбрать фото из галереи») и выбрать снимок | Экран «Монтик появляется на свет…», затем предпросмотр героя без фона |
| 4 | Нажать «Это Монтик! Играть» | Главный экран; поверх него ситуация «Первый кошелёк Монтика» (в кошельке 50 монет) |
| 5 | Выбрать «Купить еду и ночь в домике (−30)» | Диалог «Отличный выбор!» с объяснением «Почему так?»; затем урок «Еда, вода и дом»; в кошельке 20 монет, оплаченная ночь |
| 6 | «Работа → Выйти на смену» (помощник) и ответить на задание | Расчётный листок: начислено 42 (или 35 без задания), налог 13% = 5, на руки 37 (или 30); урок «Налог 13%» |
| 7 | Посмотреть полосу сил на главном экране | Силы снизились на 35, еда и вода на 15 |
| 8 | «Магазин → Еда и вода»: купить обед и воду | Полосы еды и воды выросли, монеты списаны |
| 9 | «Магазин → Одежда»: купить кепку и футболку, во вкладке «Гардероб» надеть | Одежда видна на Монтике; в гардеробе видно «Ещё ночей» |
| 10 | «Подушка»: отложить 20 монет | Прогресс подушки растёт; при первом накоплении открывается урок |
| 11 | «Спать» → «Лечь спать в домике» | Монтик засыпает: открывается экран сна (см. 11а–11в); после пробуждения — день 2 и финансовый дневник (заработал / потратил / отложил) |
| 11а | «Спать» → «Лечь спать в домике» → дождаться будильника (полная ночь — 12 настоящих минут; для быстрой проверки — «Разбудить раньше») | Экран «Монтик спит»: ночная комната, «Проспал / До пробуждения», полоска сна; можно закрыть игру и открыть позже — время досчитано; при звонке — экран «Просыпайся!» |
| 11б | На будильнике нажать «Отложить на 15 минут» | Монтик спит дальше; через 18 настоящих секунд будильник звонит снова |
| 11в | На будильнике нажать «Выключить» | Экран «Доброе утро!»: Монтик стоит возле кровати, сколько проспал, силы, «выспался / не выспался» и цена смены в силах; «Начать день» открывает комнату |
| 11г | Новая игра → «Нарисуй Монтика» | На экране белый человечек (контур без цвета); под ним ряд «Кто твой Монтик?»: Белый, Синий, Зелёный, Розовый, Фиолетовый, Рыжий |
| 11д | Выбрать «Зелёный», коснуться ушей и выбрать красный; «Готово!» | Монтик зелёный, красные ушки; после перезапуска игры тот же. Повторное касание заготовки стирает раскраску |
| 11е | Оставить белого человечка и нажать «Готово!» | В комнате и после сна — белый пушистый Монтик из макета; «Профиль» на телефоне позволяет перекрасить |
| 12 | Повторять работу и сон, пока не наберётся 150 монет; «Путешествие → Купить билет в Москву» | Маршрут из трёх остановок; на каждой ситуация с выбором и объяснением |
| 13 | После трёх остановок открыть «Дневник» | Навыки выросли, в журнале есть записи, Казань стала доступна |
| 14 | «Родитель»: ответить 56, придумать PIN, войти | Цели обучения с отметками ✅, прогресс, навыки, журнал |
| 15 | Закрыть приложение и открыть снова | Прогресс, монеты и рисунок Монтика на месте |
| 16 | Включить режим полёта и повторить пункты 6–8 | Игра работает так же: интернет не нужен |
| 17 | Кнопка «Назад» на внутренних экранах | Возврат на главный экран |
| 18 | «Рисунок» на главном экране, затем «Отмена» | Возврат в игру без потери прогресса |

## Сквозной сценарий ТЗ (Приложение А)

Для экспертов быстрее всего: «Телефон → Настройки» (7 × 8 = 56, PIN) → «Сбросить тестовый профиль» — демо-режим включится сам.

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| А1 | Установить APK и открыть | Заставка и история, затем окно «Как играть: три решения» (после первой ситуации) |
| А2 | Профиль без имени, телефона и почты | Регистрации нет — только игровое имя героя |
